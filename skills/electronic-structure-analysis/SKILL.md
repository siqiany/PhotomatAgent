# Electronic Structure Analysis

Placeholder scientific SOP. This phase only demonstrates how a Skill is
loaded and surfaced; the loop does not yet select skills automatically.

## Scope

Infrared photodetection materials (e.g. III-V semiconductors, narrow-gap
compounds).

## Procedure (placeholder)

1. Define the material and its target property (band gap, DOS near Fermi level).
2. Run a mock/VASP calculation via the scientific backend.
3. Record the result as Evidence with provenance.
4. Compare with literature; promote to a Claim only when supported.
5. Mark open questions explicitly.

## Notes

- Never treat mock results as real science.
- Record every calculation as a CalculationRecord for provenance.
