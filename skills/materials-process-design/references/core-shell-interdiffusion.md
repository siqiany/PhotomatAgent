# Core–shell interdiffusion

Record core and shell identities, size and shell-thickness distributions, thermal history, atmosphere, and characterization limits. Distinguish elemental redistribution, strain, and phase change before fitting diffusion.

Use the source Methods and elemental mapping to establish a baseline. Register independent untreated and treated sample IDs, then add an explicit characterization checkpoint and a stop branch if the shell identity is unresolved. Use `method_search` with `core_shell_dot` when comparing approaches. The homogeneous Brus approximation cannot resolve an interdiffused interface.

Check elemental profiles before and after treatment and control the electron dose. Optical peak shifts also depend on strain and confinement, so a peak shift without composition-sensitive data leaves diffusion UNKNOWN.

Describe radial composition separately from mean composition and from a
device-scale doping gradient. Retain a homogeneous-alloy calculation as a
reference for that homogeneous sample. Treat transfer to a radial interface as
a separate modeling hypothesis with an observable that can distinguish it.
When a spatial profile is unresolved, record sample architecture as UNKNOWN.
Keep radial and homogeneous hypotheses separate until sample-bound evidence
can discriminate them. A uniform calculation remains a reference scenario.

Reference system: [Heat-induced Zn diffusion in CdSe–CdS–ZnS quantum dots](https://pubs.rsc.org/en/content/articlelanding/2015/cc/c4cc08647c).
